# REAL LIFE BUILDINGS — Forge 1.20.1

Техническая альфа мода для Minecraft Java Edition 1.20.1 и Minecraft Forge 47.2.0. Требуется Java 17.

## Возможности альфа-версии

### Строительство
- Планшет строителя с разделами «Материалы», «Проекты» и «Инструменты».
- Автоматическое строительство стартового одноэтажного дома 7×9.
- Чертёж загородного двухэтажного дома 9×11 с шестью комнатами.
- Поворот проекта на 90° с помощью Shift.
- В режиме выживания строительство проверяет и расходует материалы; в творческом режиме материалы не требуются.
- Выбор проекта в интерфейсе пока меняет предпросмотр; фактическое размещение доступно для реализованных чертежей.

### Блоки, мебель и техника
- Строительные материалы: бетонные и каменные панели, фасадное стекло, дубовый пол, красный кирпич, тёмный бетон и плитка террасы.
- Интерьер: кухонная стойка, стул, диван, шкаф.
- Умная лампа с ручным переключением и управлением редстоуном.
- Дверной звонок со звуком, частицами и редстоун-сигналом.
- Холодильник и шкаф с хранилищем на 27 слотов и сигналом компаратора.
- Микроволновка готовит сырую еду из инвентаря игрока и выдаёт редстоун-сигнал во время работы.
- Кухонная стойка открывает стандартный интерфейс верстака.
- Стул и диван позволяют персонажу садиться.

### Еда
- Сэндвич, консервы и фруктовый сок.
- Рецепты крафта, локализация RU/EN.

## Установка
1. Установи Minecraft Java Edition 1.20.1.
2. Установи Minecraft Forge 47.2.0.
3. Скачай JAR из успешного артефакта GitHub Actions в репозитории.
4. Помести JAR в папку `.minecraft/mods`.
5. Запусти игру через профиль Forge.

## Сборка из исходников
- JDK 17.
- Gradle Wrapper проекта.
- Команда: `./gradlew build` (Windows: `gradlew.bat build`).

GitHub Actions автоматически собирает мод при push в ветку `main`. Готовый JAR прикрепляется к запуску как workflow artifact.

## Текущий статус
Это ранняя техническая альфа, а не законченный релиз. Некоторые интерфейсы и функции являются прототипами. Полноценные NPC, экономика, транспорт, система недвижимости и другие крупные системы ещё не реализованы.
