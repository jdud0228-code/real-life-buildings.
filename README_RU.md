# REAL LIFE BUILDINGS — Forge 1.20.1

Первая альфа-версия проекта для Minecraft Java Edition 1.20.1 и Minecraft Forge 47.x.

## Что есть в прототипе
- предмет «Планшет строителя»;
- открытие стартового меню клавишей M;
- базовая регистрация мода и русская/английская локализация.

## Сборка
Требуется JDK 17. В корне проекта выполните:
```bash
gradle build
```
Готовый JAR появится в `build/libs/`.

## Облачная сборка
GitHub Actions автоматически собирает проект при push и позволяет скачать JAR из раздела Actions → Artifacts.

Это ранний прототип. Каталог зданий, размещение построек, NPC, экономика и остальные системы пока не реализованы.
