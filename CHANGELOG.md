# Changelog

All notable changes to Real Life Buildings are documented here.

## [0.1.0-alpha] - 2026-10-31

### Added
- Builder Tablet with starter house construction and project selection UI.
- Country Cottage blueprint for a two-storey, six-room house.
- Building materials, furniture, kitchen appliances, fridge and wardrobe storage.
- Smart lamp, doorbell and microwave redstone interactions.
- Comparator output for fridge and wardrobe inventories.
- Microwave cooking for supported raw foods.
- Sandwich, canned food and fruit juice items with crafting recipes.
- Russian and English localization for microwave interaction messages.

### Technical
- Minecraft 1.20.1
- Minecraft Forge 47.2.0
- Java 17

### Status
This is an **alpha** development build. Features are incomplete and compatibility
or world-safety issues may remain. Back up worlds before testing. Do not treat
this release as a stable production version.
